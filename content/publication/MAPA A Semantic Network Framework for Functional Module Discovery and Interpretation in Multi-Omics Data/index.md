title: "MAPA: A Semantic Network Framework for Functional Module Discovery and Interpretation in Multi-Omics Data"

abstract: Multi-omics technologies generate high-dimensional molecular signatures that provide unprecedented opportunities to uncover biological mechanisms. MAPA integrates molecular interactions and pathway-level functional context into a unified semantic-biological network and uses retrieval-augmented large language models to produce structured, literature-informed interpretations of functional modules.
